# دفتر الحساب (Daftar Al-Hisab)

تطبيق فلاتر لإدارة يوميات العمال، الورشات/المشاريع، والمدفوعات — مصمم لأصحاب الورش والمقاولين لتتبع أجور العمال اليومية والسلف والرصيد المستحق لكل عامل.

## المزايا

- **اليوميات**: تسجيل يومية عمل لكل عامل (الاسم، الورشة، الأجر، ملاحظات) مع إنشاء تلقائي للورشة إذا لم تكن موجودة.
- **الورشات والمشاريع**: عرض كل ورشة مع إجمالي أيام العمل، التكلفة الإجمالية، آخر نشاط، وحالة المشروع (نشط / مكتمل جزئياً / مكتمل).
- **العمال**: قائمة بجميع العمال مع الرصيد المستحق لكل واحد منهم.
- **الملف الشخصي للعامل**: الرصيد المستحق، إجمالي اليوميات، إجمالي السلف، سجل الحركات الكامل، تصدير كشف حساب PDF، ومشاركة سريعة.
- **المدفوعات**: تسجيل دفعات أسبوعية أو سلف نقدية أو تسويات حساب لكل عامل.
- **التقارير**: نظرة عامة على التكلفة حسب كل ورشة والعمال الأكثر استحقاقاً.
- **الإعدادات**: اختيار العملة، الوضع الداكن، تذكير يومي، وحذف كافة البيانات.
- دعم كامل للغة العربية والاتجاه من اليمين لليسار (RTL).
- تخزين محلي بالكامل (SQLite) — لا حاجة لإنترنت أو خادم.

## البنية التقنية

- **Flutter** (Material 3) + **Provider** لإدارة الحالة.
- **sqflite** لقاعدة بيانات محلية.
- **shared_preferences** لحفظ إعدادات المستخدم.
- **pdf** / **printing** لتصدير كشوف الحساب.
- **share_plus**, **url_launcher** للمشاركة والاتصال المباشر بالعامل.

## البناء محلياً

```bash
flutter pub get
dart run flutter_launcher_icons
flutter build apk --release
```

سيكون ملف الـ APK جاهزاً ضمن `build/app/outputs/flutter-apk/`.

## البناء عبر GitHub Actions

يحتوي المستودع على ورك-فلو جاهز (`.github/workflows/build.yml`) يقوم تلقائياً ببناء الـ APK عند كل push على `main`، ورفع الملف كـ artifact. عند إنشاء tag يبدأ بـ `v` (مثل `v1.0.0`) سيتم إنشاء إصدار (Release) تلقائياً مع إرفاق ملفات الـ APK.
